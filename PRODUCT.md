# Pricing Tool

## Purpose and audience

Application reviewers can explore a completed lending-pricing interface, follow its calculation explanations, and try the quote lifecycle without creating an account.

## Product boundaries

Home, Personal and Commercial retain separate inputs, engines and saved records. Shared operational envelopes contain workflow, assignments, comments and history. Every product, customer, score calibration and lender policy value is fictional. Public regulatory arithmetic remains explanatory; this product makes no financial offer or credit decision.

## Experience

The application opens directly on a three-product workspace. Preserve the existing paper-light workspace, dark evergreen navigation, product-specific colour accents, serif tabular figures, structured form sections and transparent results. The app is an operating interface, not a marketing landing page.

Each visitor owns browser-local records, with useful initial scenarios and a reset action. There are no accounts, roles, administration, live ingestion, shared data or server endpoints. Errors must explain how to recover, and saves must be acknowledged only after storage commits.

## Accessibility

Keyboard operation, visible focus, meaningful headings, text-labelled status, polite result updates, reduced motion, and responsive desktop/mobile layouts are required.
